# Simple Calculator

A responsive calculator web application built with HTML, CSS, and JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Percentage, decimal, and double-zero input
- Clear (`AC`) and delete (`DE`) controls
- Display of errors for invalid expressions
- Neumorphic interface with a responsive layout

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/AnshSojitra/Simple-Calculator.git
   ```

2. Open `index.html` in your web browser.

## Project Structure

- `index.html` - Calculator markup
- `style.css` - Layout and visual styling
- `script.js` - Calculator behavior

## Technologies

- HTML5
- CSS3
- JavaScript
